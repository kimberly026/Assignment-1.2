# Assignment 1.2 — Development Environment Setup

## 1. Aim

To set up a web development environment on a computer using Visual Studio Code, Node.js, and the required extensions, and to run a simple HTML webpage in a browser.

## 2. Requirements

- Visual Studio Code
- Node.js (LTS version)
- Live Server extension
- Prettier extension
- Web browser
- Computer with an internet connection

## 3. Procedure

### Step 1: Install Visual Studio Code

Visual Studio Code was downloaded from the official website, [https://code.visualstudio.com/](https://code.visualstudio.com/), and installed on the computer. It is used to write, edit, and manage HTML, CSS, and JavaScript code.

### Step 2: Install Node.js

The LTS version of Node.js was downloaded from [https://nodejs.org/](https://nodejs.org/) and installed. Node.js allows JavaScript to run outside a web browser. The installation also includes npm (Node Package Manager), which is used to manage JavaScript packages.

### Step 3: Install Required Extensions

The following extensions were installed in Visual Studio Code:

1. **Live Server:** Used to launch HTML webpages in a browser and automatically refresh them when changes are saved.
2. **Prettier:** Used to format code and improve readability.

### Step 4: Create the Project Folder

A folder named `web-development-practice` was created and opened in Visual Studio Code.

### Step 5: Creating the Required Files

Three files were created inside the project folder:

- `index.html` — Contains the structure of the webpage.
- `style.css` — Controls the appearance and design of the webpage.
- `script.js` — Adds interactivity to the webpage.



### Step 6: Run the HTML File Using Live Server

The `index.html` file was opened in Visual Studio Code. The Live Server extension was used by right-clicking the file and selecting **Open with Live Server**.

The webpage opened in the default browser, displaying the heading, paragraph, and button. The button was clicked to verify that the JavaScript functionality was working correctly.

### Step 7: Verify Node.js and npm Installation

The integrated terminal in Visual Studio Code was opened by selecting **Terminal → New Terminal**.

The following commands were executed:

```
node -v
```

This command displays the installed Node.js version.

```
npm -v
```

This command displays the installed npm version.

## 4. Observation

The project folder contained the three required files: `index.html`, `style.css`, and `script.js`. The HTML file was linked to the CSS and JavaScript files. Live Server displayed the webpage in the browser, and the terminal commands were used to verify the installation of Node.js and npm.

## 5. Result

The web development environment was set up using Visual Studio Code, Node.js, Live Server, and Prettier. The required project folder and files were created, and a sample webpage was prepared to test HTML, CSS, and JavaScript functionality.
